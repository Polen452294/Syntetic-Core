# Проверки выделенного проекта

[English](../../VERIFICATION.md) · Русская версия

Дата: 8 ноября 2026. Платформа: Windows x86-64, Python 3.12.

- Самостоятельная установка в собственное `.venv`: выполнена.
- Unit/regression: 149 passed.
- Настоящий Chromium: 1 passed, 26,86 с. Проверены runtime discovery, создание
  Android-профиля, локальная навигация, согласованность CPU/RAM document/Worker,
  touch=5, webdriver=false и localStorage при повторном открытии профиля.
- mypy публичного API/CLI: успешно, 3 модуля.
- Ruff и проверка форматирования: успешно, 96 Python-файлов.
- Wheel и sdist: успешно собраны через `python -m build`.
- Импорт из отдельно установленного wheel под Python `-I`: успешно; проверено
  присутствие JS и WebKit media ресурсов. Тот же wheel прошёл 149 unit-тестов.
- Настоящий browser test повторён из wheel после фиксации runtime-зависимостей:
  1 passed, 29,88 с; исходный `src` для импорта пакета не использовался.
- `pip check`, все относительные ссылки README/docs и SHA-256 63 перенесённых
  engine/resource файлов: успешно.

Тест браузера использует только локальный HTTP-стенд. Ротация провайдеров проверяется
моками: отказ/таймаут API, подтверждение нового IP, блокировка занятого канала,
общий modem ID, credentials и отмена. Новых платных provider API вызовов не было.

Linux/macOS/ARM64, отдельная Camoufox-сборка, WebKit и настоящие IP-провайдеры в новом
проекте пока не прошли самостоятельную приёмку. Исторические свидетельства исходной
системы не выдаются за новые испытания выделенного пакета.
