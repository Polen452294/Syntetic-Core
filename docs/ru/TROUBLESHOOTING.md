# Диагностика

[English](../TROUBLESHOOTING.md) · Русская версия

## RuntimeCompatibilityError

Запустите `syntetic-core doctor` в том же виртуальном окружении, режиме дисплея и
пользователе ОС. Проверьте `installed`, `smoke_test`, `limitations` и `parameters`.
Не меняйте manifest вручную, чтобы обойти ошибку: generator и factory должны
согласоваться с фактическим runtime. iOS на Windows не поддерживается.

## BrowserLaunchError / driver guard

Выполните `syntetic-core prepare --engine chromium` до запуска задач. Проверьте
Playwright 1.62.0, установленные бинарники и требуемые системные библиотеки.
Патч должен находиться в драйвере именно текущего Python-окружения.
Для Camoufox отдельно выполните `tools/setup_browser.py` и проверьте путь сборки.

## ProfileValidationError

Сохранённая identity, hash, движок, версия или наблюдаемая геометрия не совпали.
Сохраните данные для анализа. Создайте новый ID для новой конфигурации вместо
удаления отдельных identity-файлов или пересчёта хеша использованного профиля.
Для мобильной страницы нужен корректный `<meta name="viewport">`; сравнение
учитывает native viewport scale, но не разрешает произвольную смену устройства.

## ProfileLockedError

Профиль или proxy/modem уже используется. Дождитесь завершения owner либо
используйте отдельный профиль/канал. Файл `.lock` может существовать после закрытия:
блокировка определяется ОС, а не наличием файла. Не удаляйте lock-файлы активных задач.

## Неполная страница или запрещённые запросы

Проверьте точные домены ресурсов, redirects и `www`-варианты. Для локального стенда
нужен также `trusted_local_target_hosts`. Временно отключите явную resource
оптимизацию для сравнения; блокировка CSS/шрифтов меняет рендеринг и может мешать
сайту. Включайте фильтры по измерению задачи.

## IP не изменился

Проверьте метод API, credentials, модель тарифа и правильный физический канал.
Увеличение timeout не исправляет ответ отказа. Успешный HTTP 2xx может означать
только принятие задания; ядро ждёт новый IP через реальный upstream. Не запускайте
ротацию повторно вслепую при неопределённом результате.

## Cookies/localStorage не сохраняются

Используйте тот же ID и profile_root, завершайте async context manager штатно.
Разные origin/поддомены имеют разную область storage. `fresh=True` предназначен
для одноразового профиля, а не постоянной авторизации. Не удаляйте browser-data
между открытиями. Сайт может самостоятельно очищать/ограничивать хранилище.

## Слишком большой расход RAM

Ограничьте параллельность и измерьте размер типичной страницы. Отдельный persistent
context запускает отдельный браузер. Этот пакет не содержит resource supervisor
и cgroups исходного кластера. Автоматических retry с запуском ещё одного браузера
для маскировки нехватки ресурсов нет.
