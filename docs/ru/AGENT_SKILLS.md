# Навык для Codex и Claude Code

[English](../AGENT_SKILLS.md) · Русская версия

Общий навык находится в [skills/syntetic-core/SKILL.md](../../skills/syntetic-core/SKILL.md).
Он обучает агента пользоваться существующим ядром: постоянными профилями,
эмуляцией устройств, парсингом, проверками окружения и сменой IP в рамках задачи.
Включены помощник запуска, справочные примеры, wheel и закреплённые зависимости.
MCP-сервер и ключ API модели для самого навыка не нужны.

## Установка для текущего пользователя

Из каталога проекта:

```powershell
.\.venv\Scripts\python.exe tools/install_agent_skills.py
```

С активированным окружением на другой ОС:

```bash
python tools/install_agent_skills.py --agent both
```

Каталоги по умолчанию:

| Потребитель | Каталог навыка |
|---|---|
| Проверенный каталог Codex desktop/CLI этого компьютера | `~/.codex/skills/syntetic-core` |
| Личные навыки Claude Code | `~/.claude/skills/syntetic-core` |

Для соответствующих каталогов учитываются `CODEX_HOME` и `CLAUDE_CONFIG_DIR`.
`--agent codex` или `--agent claude` устанавливает навык только для одного инструмента.
Для Codex доступны `--codex-location desktop` (по умолчанию), `modern` для
`~/.agents/skills` и `both`. По умолчанию выбран каталог, проверенный на этом компьютере.
Актуальная официальная документация Codex описывает `~/.agents/skills`; используйте
`modern`, если ваш клиент читает этот каталог. Некоторые сборки читают оба и могут
показать две копии. Установщик прежние копии не удаляет.

Установка сохраняет перечень собственных файлов и указатель на проект. Повторный
запуск обновляет управляемую копию, если её файлы не менялись локально. Чужой навык
или локальные изменения не перезаписываются. Настройки разрешений агентов не меняются.

## Вызов

Codex:

```text
Используй $syntetic-core для парсера моего сайта с постоянным Android-профилем.
```

Claude Code:

```text
/syntetic-core Сделай браузерный парсер с постоянным профилем и результатом в JSON.
```

Описание допускает и автоматический выбор навыка по подходящей задаче. Если новый
навык не появился, откройте новую сессию или перезапустите клиент. Во время подготовки
Claude Code не найден в PATH этого компьютера; личные файлы навыка устанавливаются
и без установки самого приложения.

## Запуск ядра

Относительно каталога установленного навыка:

```bash
python scripts/runtime.py info
python scripts/runtime.py cli --profiles /absolute/task/profiles doctor
python scripts/runtime.py python /absolute/path/to/task.py
```

Помощник использует явный `SYNTETIC_CORE_HOME`, сохранённый указатель на проект,
вмещающий каталог проекта либо подготовленное окружение навыка. Аргументы и рабочий
каталог сохраняются; shell для запуска не используется. `info` только находит файлы.

Если исходный проект недоступен, можно установить включённый wheel независимо:

```bash
python scripts/runtime.py setup
python scripts/runtime.py cli prepare --engine chromium
```

Окружение по умолчанию: `~/.cache/syntetic-core/skill-runtime`. Для своего каталога
используйте `setup --venv /absolute/path` и задайте `SYNTETIC_CORE_SKILL_RUNTIME`.
Нужен Python 3.12+. Установка навыка не запускает браузеры и API провайдеров.
Подготовка браузера выполняется отдельной явной командой.

## Перенос и обновление

Исходный ZIP и sdist содержат `skills/syntetic-core`. Скопируйте эту папку в каталог
навыков нужного инструмента или запустите установщик из исходного проекта.
Отдельный `dist/syntetic-core-skill.zip` содержит только переносимую папку навыка.
Секреты и профили в поставку не входят. При выпуске изменений ядра обновляйте включённый
wheel; бинарники браузеров устанавливаются отдельно.

При разработке проверьте формат `SKILL.md`, `tests/test_agent_skills.py`, команды
`info`, передачу аргументов и установку во временный домашний каталог. Поведение
ядра проверяется существующими unit/browser-наборами.

Форматы основаны на официальных инструкциях [Codex](https://learn.chatgpt.com/docs/build-skills)
и [Claude Code](https://code.claude.com/docs/en/skills).
