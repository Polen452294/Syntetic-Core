# Эмуляция устройств, подмена цифровых отпечатков (Fingerprints) и обход антифрода

[English](../EMULATION.md) · Русская версия

Syntetic Core спроектирован для симуляции реальных сессий человека в браузере, которые не распознаются современными антифрод- и антибот-системами (включая **Cloudflare Turnstile / Bot Management, DataDome, Akamai Bot Manager, Kasada, Yandex SmartCaptcha и Антифрод, Google reCAPTCHA v2/v3/Enterprise, CreepJS, FingerprintJS Pro и Pixelscan**).

Для достижения полной неотличимости от реального пользователя ядро координирует четыре уровня системы:
1. **Физический хост:** Windows/Linux/macOS, процессор и видеокарта сервера/компьютера.
2. **Браузерный движок:** Реальный Chromium, модифицированный Camoufox (Firefox) или WebKit.
3. **Рецепт устройства и связность (Device Coherence):** Связанные между собой параметры профиля.
4. **Слой JavaScript и CDP:** Активная модификация окружения DOM, сетевых заголовков и фоновых потоков WebWorkers.

## 1. Спектр подменяемых цифровых отпечатков (Fingerprints)

| Отпечаток / API | Camoufox (Stealth Firefox) | Chromium (Playwright + CDP) | WebKit (iOS / macOS) |
|---|---|---|---|
| **Целевая ОС и платформа** | Низкоуровневая подмена в C++ движка (Win/macOS/Linux) | CDP User-Agent, `navigator.platform`, Client Hints (`Sec-CH-UA-Platform`) | Нативный Safari User-Agent и параметры платформы iOS |
| **Canvas 2D** | Встроенный в C++ движка генератор шума Canvas | Постоянный микросдвиг сабпиксельного рендеринга текста (±0.02 px) в `fillText`/`strokeText` | Слой микросдвига координат рендеринга текста |
| **WebGL 1 и 2** | Встроенная абстракция видеодрайвера Camoufox | Эмулируемые unmasked vendor, unmasked renderer, список расширений и лимиты | Согласованные vendor и renderer под целевую систему |
| **Web Audio API** | Нативный семплер аудиобуфера с добавлением шума | Детерминированный математический шум в AudioBuffer и DynamicsCompressor | Слой подмешивания шума в аудио-буфер |
| **Client Hints (`Sec-CH-UA`)** | Не применимо к архитектуре Gecko | Полные CDP Client Hints: бренды, архитектура, битность, флаги мобильности | Не применимо к WebKit |
| **CPU (`hardwareConcurrency`)** | Единый семплер ядер процессора в движке и JS | Подмена через CDP и синхронизация свойства во всех WorkerNavigator | Синхронизированное число ядер в JS |
| **RAM (`deviceMemory`)** | API отсутствует (соответствует поведению реального Firefox) | Синхронизация `navigator.deviceMemory` в основном окне и WebWorkers | API отсутствует (соответствует поведению Safari) |
| **Battery API** | API отсутствует (соответствует поведению реального Firefox) | Полная эмуляция BatteryManager с событиями зарядки и разрядки | API отсутствует (соответствует поведению Safari) |
| **Шрифты и FontFaceSet** | Нативная фильтрация доступных шрифтов | Фильтрация `FontFaceSet` в соответствии со шрифтами целевой ОС | Фильтрация шрифтов целевой платформы |
| **Медиа-устройства** | Нативные пресеты медиа-устройств | Стабильные идентификаторы и названия в `navigator.mediaDevices.enumerateDevices` | Эмулируемый список медиа-устройств |
| **Синтез речи (голоса)** | Нативные голоса Camoufox | Подмножество системных голосов строго под целевую ОС и язык | Нативные голоса окружения |
| **Тач и сенсоры** | Десктоп без сенсорного ввода | Android: `maxTouchPoints = 5`, тач-события, эмуляция сенсоров через CDP | Тач-события и жесты iOS |
| **Датчики движения** | Нативная политика сенсоров | Android: Акселерометр, Гироскоп и Магнитометр через CDP | Эмуляция датчиков при доступности |
| **Флаг автоматизации** | Строго `navigator.webdriver = false` | Строго `navigator.webdriver = false` (флаги автоматизации вычищены) | Строго `navigator.webdriver = false` |
| **Маскировка функций** | Нативный C++ код Firefox | Двойной Proxy/WeakMap слой: `Function.prototype.toString` возвращает `[native code]` | Нативная маскировка инспекции JS-функций |

## 2. Связные рецепты оборудования (`device_coherence`)

Классическая ошибка простых антидетект-скриптов — **несогласованность параметров** (например, User-Agent iPhone при видеокарте NVIDIA и 8 ядрах процессора, или мобильный экран с десктопными Client Hints). Системы антифрода мгновенно выявляют такие аномалии.

Syntetic Core использует жестко связанные аппаратные рецепты (`recipe_id`):
- **Apple Silicon macOS:** Chromium на M1/M2 строго использует архитектуру ARM64, 8 ядер CPU, видеокарты семейства Apple GPU и соответствующую битность в Client Hints.
- **Android Mobile:** Точное сопоставление моделей (Samsung Galaxy S21/S22/S23, Google Pixel 6/7/8, Xiaomi, OnePlus) с их реальными видеочипами (Adreno / Mali), 8 ядрами CPU, 5 точками мультитача и правильной геометрией экрана/DPR.
- **iOS / iPadOS:** Ограничение iPhone до 4/6 ядер, iPad до 4/8 ядер с соответствующими коэффициентами Retina DPR.
- **Геометрия экрана и DPR:** Размеры экрана и DPR строго ограничивают допустимый список видеокарт во избежание подозрительных сочетаний.
- **Часовой пояс и геолокация:** Координаты генерируются в радиусе реальных мегаполисов, точно соответствующих заданному часовому поясу.

## 3. Устранение утечек CDP и признаков автоматизации

Системы защиты детектируют автоматизированные браузеры через артефакты CDP, глобальные переменные и переопределенные JS-функции:
1. **Патч владения целями (Playwright Target Ownership Patch):** Стандартный драйвер Playwright конфликтует с контроллером CDP при перехвате новых целей (targets). Syntetic Core применяет патч к Playwright 1.62.0, гарантирующий разделение владения целями и исключающий зависания и временные аномалии CDP.
2. **Маскировка под нативный код `[native code]`:** Все переопределенные методы (например, `navigator.webdriver`, `WebGLRenderingContext.prototype.getParameter`, `AudioContext`) обернуты в архитектуру Proxy и WeakMap. Любая проверка через `Function.prototype.toString.call(target)` или обращение к `.name` и `.length` возвращает подлинные метаданные нативной функции.
3. **Очистка артефактов автоматизации:** Полное удаление переменных `window.cdc_`, внутренних флагов runtime Chromium и маркеров Playwright до загрузки клиентских скриптов.

## 4. Ранняя инициализация WebWorkers

Главная слепая зона обычных библиотек автоматизации — фоновые потоки WebWorkers. Скрипты антифрода (включая Cloudflare Turnstile и DataDome) запускают DedicatedWorkers, SharedWorkers, ServiceWorkers или создают OffscreenCanvas в воркере, опрашивая параметры железа напрямую из потока, куда обычные скрипты страницы не дотягиваются.

Syntetic Core решает эту проблему через **выделенный CDP Worker Controller**:
- Рекурсивно перехватывает создание любых воркеров в момент их инициализации.
- Приостанавливает выполнение воркера до запуска его скрипта.
- Внедряет в воркер параметры CPU, памяти, User-Agent, платформы, Client Hints и настройки WebGL offscreen canvas.
- Возобновляет работу воркера только после того, как его цифровой отпечаток полностью синхронизирован с основным документом.

## 5. Постоянные Cookies, хранилище и прогрев (Warming) профилей

Антифрод-системы присваивают высокий уровень риска новым браузерам с пустым кэшем и отсутствием истории посещений. Такие профили сразу получают капчи и блокировки.

В Syntetic Core профили **постоянны по умолчанию**:
- Полное сохранение `cookies`, `localStorage`, `sessionStorage`, `IndexedDB` и дискового кэша между перезапусками.
- Возможность поэтапного **прогрева профилей (warming)**: накопление истории посещений поисковых систем, авторитетных сайтов и соцсетей формирует доверие антифрода (trust score).
- Данные профиля изолированы в `data/profiles/<id>/`, защищены файловыми блокировками операционной системы (`ProfileLock`) и контролируются контрольными суммами `config_hash`.

## 6. Эмуляция человеческого поведения (ПФ — Поведенческие Факторы)

Алгоритмы антифрода анализируют кинематику курсора мыши, паузы между нажатиями клавиш и динамику прокрутки. В ядро встроен полноценный поведенческий модуль:
- **Кинематика курсора:** Движение мыши по кривым Безье с естественными микроколебаниями, случайными ускорениями и промахами с последующей доводкой до элемента.
- **Человеческий ввод текста:** Посимвольный набор с задержками по логнормальному распределению, случайными опечатками и их исправлением через Backspace.
- **Инерционный скроллинг:** Плавная прокрутка с ускорением, замедлением и паузами на чтение контента.
- **Эмуляция присутствия на странице:** Методы `session.maintain_presence(seconds)` и `UXActivityDispatcher` генерируют микродвижения курсора и легкий скроллинг, симулируя активного живого пользователя.

## 7. Границы физического хоста и ответственное использование

Несмотря на глубокую подмену отпечатков, фундаментальные свойства физического хоста остаются неизменными:
- Реальные микрокоманды процессора хоста и физическая архитектура чипа (например, выполнение x86-инструкций при эмуляции ARM64) определяются реальным железом.
- Сетевой стек ядра ОС хоста (например, размер окна TCP) принадлежит реальной операционной системе.
- Движок WebKit работает только на Linux и macOS (на Windows запуск запрещён).

Всегда согласовывайте геолокацию прокси, часовой пояс и язык профиля во избежание географических нестыковок в сетевом трафике.
